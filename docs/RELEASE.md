# 0.3.0-preview.8

- Windows 原生 OpenConnect Array 隧道，Clash 保持运行，校园目标按 IP/域名分流。
- GUI 新增自动选择、校园直连、Clash 联动三种连接方式，以及重新检测、代理设置、连接测试和异常恢复。
- 内核支持从运行进程、Clash Verge 目录、PATH 和常见安装目录查找，也可在 GUI 选择文件并验证版本。配置联动目前要求 Clash Verge 配置结构。
- 运行中的代理异常时阻止自动降级；不关闭 Clash，不切换现有规则模式或外网节点。
- 无运行中代理时可使用校园直连；公网 DNS 回退不依赖 Clash，精确校园域名临时映射在断开或恢复时清理，已有同名 hosts 条目不会被覆盖。
- 本地密码通过受限命名管道传给隐藏管理员后台，密码不落盘。异常恢复结果显示在 GUI 内。
- 校园 DNS 优先，公网 DoH 与可选本地备用表回退；失败域名保留诊断并允许其他目标继续连接。
- 将解析结果精确缓存至 Clash；本地超算备用池优先使用能返回 SSH 握手的节点。
- 修复后台状态作用域、连接退出诊断与 ZIP 打包；补充自动化检查。
- 默认目标为空；个人账号、IP、目标表、参考文件和运行数据全部留在本地。发布包附 SHA256。

验证：PowerShell 安全与模式测试、GUI 构建和设置保存、Rust 单元测试、fmt/clippy，以及现有 Clash 内核检测和外网 HTTP 200。测试未关闭 Clash 或修改其运行配置。

用户随后已确认本版本在 Clash 开启和关闭两种环境下均可成功登录。此前也已确认原生连接及校园 SSH 登录成功。长时间运行、网络切换和第二台电脑仍待验证，版本仍为预发布。
