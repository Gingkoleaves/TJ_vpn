# 0.2.0-preview.4 发布说明

Windows x64 便携 GUI 预发布。首次原生连接已由用户确认成功。

- 新增中文 WinForms 面板及 Rust `TongjiVPN.exe` 启动入口。
- 修复管理员 PowerShell 的隐藏启动标志影响面板显示；重复启动唤起已有窗口。
- 管理面板改为普通权限启动，只有连接/恢复操作提权；先显示界面，再由计时器读取网络状态，避免启动状态查询阻塞显示。升级单实例锁名，绕过旧版没有窗口的残留面板进程。
- 提供连接、请求断开、连接测试、环境检查、配置编辑和异常恢复。
- 认证仍在独立本机终端完成，密码不进入面板、配置或日志。
- GUI 关闭后连接保留；只有点击断开或关闭认证终端才结束连接。
- 新增 GUI 构建测试、启动器资源缺失检查、便携包 SHA256。

使用前需要 Windows x64、Clash Verge Rev 规则模式与 TUN、7-Zip、校园账号和首次下载网络。发布包不包含 OpenConnect；首次启动从上游下载固定版本并校验。

仓库只创建了本地 release ZIP 和 Git 标签，没有发布到 GitHub。ZIP 位于 `dist/`，解压后运行 `TongjiVPN.exe`。完整操作及校园目标限制见 README。

仍待验证：GUI 实际认证/断开流程、至少 30 分钟持续连接、休眠和网络切换、第二台电脑。没有签名 Windows exe；当前不是已验证的生产级发行版。
